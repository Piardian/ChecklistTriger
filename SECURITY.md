# Security Policy

## Supported versions

Only the current public development branch is considered supported.

## Reporting

Do not publish Telegram tokens, API keys, credentials, private configuration, or exploitable security details in public issues.

If GitHub private vulnerability reporting is enabled, use it. Otherwise, contact the repository owner through GitHub with reproducible details and without exposing secrets.

## Secret handling

Never commit API keys, Telegram bot tokens, passwords, or private configuration. If a secret is exposed, revoke or rotate it immediately; deleting the file later does not remove the secret from Git history.
